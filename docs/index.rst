my-arithmetic-llamoity
======================

Petite bibliothèque d'arithmétique servant de support au TP CI/CD :
tests sur GitLab CI et GitHub Actions, versions calculées depuis les tags git,
documentation sur Read the Docs et couverture sur Coveralls.

Installation
------------

.. code-block:: console

   $ pip install my-arithmetic-llamoity

Utilisation
-----------

>>> from my_arithmetic_llamoity import gcd
>>> gcd(12, 18)
6
